# Imagen técnica mediante Stability Matrix y ComfyUI

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 6 |
| Duración sugerida | 4 horas |
| Evidencia | Imagen, archivo fuente y ficha de procedencia. |

## Objetivo

Generar imágenes técnicas para comunicar una solución energética.

## Prerrequisitos

Prompts estructurados y ControlNet.

## Descripción

Construir flujo nodal de imagen con control de composición.

## Procedimiento

1. Instalar paquetes con Stability Matrix.
2. Construir flujo en ComfyUI.
3. Generar imagen conceptual y técnica.
4. Registrar semilla, parámetros y licencia.

## Evidencias de aprendizaje

Imagen, archivo fuente y ficha de procedencia.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.

## Relación con el proyecto integrador

Los resultados de esta guía se integran como producto parcial en el [Módulo 7](../../modulos/07-proyecto-integrador/README.md).
