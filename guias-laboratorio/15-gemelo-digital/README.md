# Integración de datos en un gemelo digital simplificado

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 6 |
| Duración sugerida | 4 horas |
| Evidencia | Gemelo digital demostrativo y código de integración. |

## Objetivo

Vincular datos o indicadores a una representación 3D del sistema.

## Prerrequisitos

Modelado 3D y visualización de datos.

## Descripción

Integrar un indicador (por ejemplo, consumo o generación) en un gemelo digital simple.

## Procedimiento

1. Importar modelo 3D depurado.
2. Definir variable a representar.
3. Actualizar color o etiqueta según dato.
4. Documentar limitaciones de uso.

## Evidencias de aprendizaje

Gemelo digital demostrativo y código de integración.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.

## Relación con el proyecto integrador

Los resultados de esta guía se integran como producto parcial en el [Módulo 7](../../modulos/07-proyecto-integrador/README.md).
