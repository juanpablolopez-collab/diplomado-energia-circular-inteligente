# Instalación de GPT4All y modelo cuantizado

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 5 |
| Duración sugerida | 3 horas |
| Evidencia | Ficha de modelo, consultas de prueba y registro de recursos. |

## Objetivo

Ejecutar un modelo de lenguaje local en CPU o GPU.

## Prerrequisitos

Cuantización y formatos GGUF.

## Descripción

Instalar GPT4All, descargar un modelo cuantizado y probar consultas sobre normas del diplomado.

## Procedimiento

1. Descargar modelo en ventana controlada de conectividad.
2. Configurar servidor API local.
3. Probar consultas con y sin contexto.
4. Registrar tiempos y memoria.

## Evidencias de aprendizaje

Ficha de modelo, consultas de prueba y registro de recursos.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.

## Relación con el proyecto integrador

Los resultados de esta guía se integran como producto parcial en el [Módulo 7](../../modulos/07-proyecto-integrador/README.md).
