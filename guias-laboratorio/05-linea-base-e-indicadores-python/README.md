# Línea base e indicadores en Python

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 2 |
| Duración sugerida | 3 horas |
| Evidencia | Notebook reproducible, tablas de indicadores y gráficos. |

## Objetivo

Construir una línea base y automatizar el cálculo de indicadores.

## Prerrequisitos

Pandas, matplotlib, conceptos de línea base e ISO 50001.

## Descripción

Depurar datos de consumo, construir perfiles horarios e indicadores y generar un reporte reproducible.

## Procedimiento

1. Cargar y limpiar el dataset.
2. Validar relaciones consumo/factura/ahorro.
3. Calcular indicadores y perfil horario h00–h23.
4. Exportar tablas y gráficos.

## Evidencias de aprendizaje

Notebook reproducible, tablas de indicadores y gráficos.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.
