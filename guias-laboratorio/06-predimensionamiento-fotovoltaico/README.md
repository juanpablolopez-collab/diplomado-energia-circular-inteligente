# Pre-dimensionamiento fotovoltaico y almacenamiento

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 3 |
| Duración sugerida | 4 horas |
| Evidencia | Pre-dimensionamiento argumentado y modelo reproducible. |

## Objetivo

Pre-dimensionar una solución solar fotovoltaica y comparar almacenamiento.

## Prerrequisitos

Irradiación, HSP, componentes fotovoltaicos y baterías.

## Descripción

Calcular potencia requerida, número de paneles, área y generación estimada para un hogar.

## Procedimiento

1. Caracterizar radiación y sombras del sitio.
2. Calcular demanda y potencia del sistema.
3. Seleccionar panel, inversor y batería.
4. Evaluar autoconsumo y sensibilidad.

## Evidencias de aprendizaje

Pre-dimensionamiento argumentado y modelo reproducible.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.
