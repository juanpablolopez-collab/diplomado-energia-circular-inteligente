# Conversión de imagen a 3D y depuración en Blender

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 6 |
| Duración sugerida | 4 horas |
| Evidencia | Modelo 3D depurado y archivo fuente. |

## Objetivo

Reconstruir un activo tridimensional a partir de una imagen.

## Prerrequisitos

TripoSR/Stable Fast 3D y conceptos de malla y textura.

## Descripción

Generar modelo 3D y depurarlo en Blender.

## Procedimiento

1. Seleccionar imagen de referencia.
2. Generar malla inicial.
3. Corregir escala, topología y texturas.
4. Exportar GLB/OBJ/STL.

## Evidencias de aprendizaje

Modelo 3D depurado y archivo fuente.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.

## Relación con el proyecto integrador

Los resultados de esta guía se integran como producto parcial en el [Módulo 7](../../modulos/07-proyecto-integrador/README.md).
