# RAG local en AnythingLLM con fuentes citables

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 5 |
| Duración sugerida | 4 horas |
| Evidencia | Asistente funcional, conjunto de pruebas y ficha técnica. |

## Objetivo

Construir un asistente con recuperación aumentada y citas verificables.

## Prerrequisitos

Embeddings, bases vectoriales y RAG.

## Descripción

Configurar corpus normativo, comparar respuestas con y sin RAG y diseñar pruebas de alucinación.

## Procedimiento

1. Cargar normas y manuales anonimizados.
2. Configurar chunking y metadatos.
3. Verificar citas y detectar referencias inventadas.
4. Documentar límites del asistente.

## Evidencias de aprendizaje

Asistente funcional, conjunto de pruebas y ficha técnica.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.

## Relación con el proyecto integrador

Los resultados de esta guía se integran como producto parcial en el [Módulo 7](../../modulos/07-proyecto-integrador/README.md).
