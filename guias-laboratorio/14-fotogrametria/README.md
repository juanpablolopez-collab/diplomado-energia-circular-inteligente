# Fotogrametría de un objeto o instalación

| Campo | Valor |
| --- | --- |
| Módulo | Módulo 6 |
| Duración sugerida | 4 horas |
| Evidencia | Modelo fotogramétrico y registro de captura. |

## Objetivo

Reconstruir un objeto o espacio mediante múltiples fotografías.

## Prerrequisitos

Meshroom/COLMAP y principios de reconstrucción multivista.

## Descripción

Capturar fotografías, reconstruir nube de puntos y malla, y depurar el resultado.

## Procedimiento

1. Planificar captura con solapamiento.
2. Procesar en Meshroom o COLMAP.
3. Limpiar malla y texturizar.
4. Validar escala con referencia conocida.

## Evidencias de aprendizaje

Modelo fotogramétrico y registro de captura.

## Criterios de calidad y seguridad

- Registrar datos, unidades, supuestos e incertidumbre.
- Conservar archivos fuente y versiones.
- No manipular instalaciones energizadas sin autorización.
- Validar con persona competente los resultados que impliquen seguridad o dimensionamiento.

## Relación con el proyecto integrador

Los resultados de esta guía se integran como producto parcial en el [Módulo 7](../../modulos/07-proyecto-integrador/README.md).
