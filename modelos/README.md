# Modelos

Aquí se registran las **fichas técnicas** de los modelos utilizados. Los pesos (`.gguf`, `.safetensors`, etc.) no se versionan: se descargan en una ventana controlada de conectividad y se ejecutan localmente.

Cada ficha debe incluir:
- Nombre y versión del modelo
- Licencia y uso autorizado
- Tamaño y memoria estimada
- Hardware probado (CPU / RTX 3050 / servidor)
- Fecha de revisión y checksum
- Riesgos conocidos y resultados de las pruebas de validación
