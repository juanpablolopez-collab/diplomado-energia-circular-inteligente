## Observaciones

- Los archivos `*.PENDIENTE.md` indican normas cuyo PDF llegó vacío (0 bytes) en la carpeta de descargas. Contienen enlaces oficiales para volver a descargarlos.
- El CONPES 4144 se recibió dos veces (`4144.pdf` y `Conpes-4144-2025.pdf`); se conservó una sola copia con nombre descriptivo.
- La Ley 697 y la Ley 142/143 apoyan también el Módulo 2 (facturación, tarifas y eficiencia), pero sus archivos están en el Módulo 1 para evitar duplicados.
- La Ley 1581 de 2012 es transversal a todo el diplomado: aplica siempre que se manejen facturas, imágenes o registros con datos personales.
- Normas citadas en el documento que aún no están en este repositorio: **Ley 30 de 1992**, **Estrategia Nacional de Economía Circular**, **RETIE**, **PAI-PROURE 2022-2030** y la regulación vigente de comunidades energéticas.
