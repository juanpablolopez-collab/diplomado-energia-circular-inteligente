# Datos

Este directorio guarda datos de ejemplo y conjuntos anonimizados para las prácticas.

**Reglas:**
- No versionar facturas, nombres, direcciones, identificadores ni datos comerciales reales sin anonimizar.
- Antes de subir cualquier archivo, verificar la política de protección de datos (Ley 1581 de 2012).
- Para conjuntos grandes, documentar origen, unidades, diccionario de datos y fecha de captura.
